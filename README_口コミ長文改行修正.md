# 嗜好の領域｜口コミの長文折り返し修正（第4版）

## 修正内容

- 商品詳細ページで英数字やURLなどが1000文字連続していても枠内に自動改行され、2カラムの幅を崩しません。
- 商品詳細の「みんなの口コミ」は**最大4行のプレビュー**を表示します。画面内の「拡大 ⤢」では全文を折り返して表示します。
- コメント入力欄でも長い文字列が枠内に折り返されます。投稿文字数制限は引き続き1000文字です。
- マイページでもコメント本文・長い商品名が枠からはみ出しません。小一覧は4行プレビュー、拡大一覧は全文表示です。
- 投稿、編集、削除、お気に入り、レビュー件数・もっと見るなど既存機能は変更していません。
- CSS/JSのクエリ文字列を変更し、旧キャッシュの読み込みを回避します。

## 上書き対象（差分ZIP）

```text
css/detail.css
css/mypage.css
html/detail.html
html/mypage.html
js/detail.js
```

DB・PHPは変更不要です。既存口コミデータはそのまま残ります。

## 導入手順

1. サイトのバックアップを取ります。
2. 差分ZIPを解凍し、**サイトのルートディレクトリ**（例：`/var/www/html/shikonoryoiki/`）に `css/`・`html/`・`js/` を上書きします。
3. ブラウザーで `Ctrl + F5` して、商品詳細ページとマイページを再読み込みします。
4. 同じ文字が1000文字続く口コミを開いて、左側の商品詳細欄やモーダルが横に伸びないことを確認します。

## 動作確認の観点

- PC画面：左側の口コミ欄が右側の商品情報を押し出さない。
- スマホ幅：1カラムに切り替わり横スクロールが発生しない。
- 通常一覧：4行で省略。拡大すると全文を読める。
- マイページ：コメント履歴から商品詳細ページへのリンクが引き続き機能する。

**注意：** HTML/CSS/JavaScriptの静的検査は実施しますが、実際のWSL・Apache・MySQL環境上での表示は未検証です。
