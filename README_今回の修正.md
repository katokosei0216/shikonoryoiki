# 嗜好の領域｜口コミのポップアップ修正・投稿履歴リンク（第2版）

## 修正内容

1. **投稿後のブラウザー警告ダイアログを表示しない**：口コミ投稿の成否を商品詳細ページの入力欄の下だけに表示する。
2. **ブラウザーの旧JSキャッシュを回避**：`detail.html` / `mypage.html` にあるCSS・JSの参照バージョンを `20261113-reviewfix2` に更新する。
3. **マイページの投稿履歴から商品詳細に移動**：マイページの小一覧・「投稿コメント履歴（拡大）」の両方で、**口コミカード全体**をクリック可能にする。右下に「商品ページを見る ›」を表示する。
4. 詳細ページから戻るときは「← 投稿コメント履歴へ」でマイページに戻れる（前回の `common.js` と連携）。

## 差分ZIPに入っている上書き用ファイル

- `html/detail.html`
- `html/mypage.html`
- `js/detail.js`
- `js/mypage.js`
- `css/mypage.css`

**DBの変更は不要です。口コミの履歴・会員データは消えません。**

## 適用手順

1. 元のファイルをバックアップ。
2. 差分ZIPを解凍して、サイトのフォルダーに**同じ構成のまま上書き**。特に `js/detail.js` と `js/mypage.js` を確実に差し替える。
3. ブラウザーで商品詳細・マイページを開き、`Ctrl + F5` で再読み込みする。

サイトが `/var/www/html/shikonoryoiki` にあるなら、例としてWSL(Ubuntu)側にZIPをコピー後：

```bash
cd /var/www/html/shikonoryoiki
sudo unzip -o /path/to/口コミ修正_差分.zip
```

※ `/path/to/` は実際にZIPを置いたフォルダーに変更。`unzip` が無い場合はWindows側で解凍し、各ファイルを同位置へ上書きしてもかまいません。

## 動作確認

1. `html/detail.html?id=399&from=search&category=cocktail` を開く。
2. カクテルに評価・コメントを投稿してもブラウザーのアラートが出ず、入力欄の下に「口コミを投稿しました。」が出ることを確認。
3. マイページの投稿コメント履歴で投稿した口コミカードをクリックすると、`detail.html?id=399&from=mypage&section=comments&category=cocktail` に移動することを確認。
4. 拡大一覧からも同様に移動できることを確認。
5. 必要に応じてF12 → Networkで`detail.js?v=20261113-reviewfix2`が読み込まれているか確認。

## 原因の補足

旧版の`js/detail.js`には`alert(data.message || ...)`がありました。修正後には投稿成功時の`alert`はありません。カクテル専用の投稿分岐は無いため、カクテルだけ警告が出るときは配置済みファイルの混在またはブラウザーのキャッシュが考えられます。実際のサーバーにはこちらから接続できないため、断定はできません。
